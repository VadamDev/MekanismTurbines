# Mekanism Turbines
Allows you to precisely calculate how much a [Mekanism mod](https://www.curseforge.com/minecraft/mc-mods/mekanism) industrial turbine can produce whith given Steam flow in mb/t.
<br> All formulas are pulled from https://ftbwiki.org/Industrial_Turbine and Mekanism source code.

## Configuration
<br> Everything is configurable using the constants at the top of the [turbine.py](https://github.com/VadamDev/MekanismTurbines/blob/main/turbine.py) file
